# 古人也搜索 · Mock 单页原型

P0-03 的 React + TypeScript 单页实现。页面使用同一 `SearchDataSource` 契约接入固定 Mock 与未来 API，开发默认展示明确的“产品原型 · Mock 数据”标识。

## 本地运行

```bash
cd front
npm install
npm run dev
```

生产构建与测试：

```bash
npm test
npm run build
```

## 已覆盖场景

- A：中秋单证据回答
- B：婚礼七步、多证据独立引用
- C：书信称谓与“称人/自称”语境区分
- N：当前语料未找到，不以常识补答
- U：现实使用历史药方，安全提醒且不展开操作细节
- `partial`、`cache`、`evidence_only` 展示兼容
- 搜索错误、详情局部失败与重试

输入 `模拟证据模式`、`模拟缓存模式`、`模拟网络错误` 或 `模拟服务错误` 可检查受控场景。通过 `VITE_DATA_SOURCE=api` 可切换至 `/api/v1`，界面组件无需改写。

## 内容边界

原型中的引文来自当前 TXT 的固定行定位，并由自动化测试逐字比对；由于真实内容负责人签核尚未完成，界面按“待内容审核 / C 级”显示，不得作为最终成品截图或已审核史料发布。
